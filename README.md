# 自販機の裏の戦い

学校のすみっこで、虫たちが硬貨を奪い合う3D物理アクションゲーム（Three.js・HTML 1ファイル）。

## モード
- **個人戦（陣取り）**：2〜7匹で硬貨を自分の陣地（ふせん）に集める
- **チーム戦（サッカー）**：赤と青に分かれて、相手のゴールに硬貨を入れる
- **鬼ごっこ**：広い専用マップで逃げる・追いかける
- **缶取り合戦**：中央のゴールド缶を自分のベースへ持ち帰る（チーム戦）
- **エリア制圧**：制圧サークルにいるとゲージが増え、100%で勝ち（個人／チーム）
- **ショック床**：くずれる床の上で最後まで生き残る
- **サーバー防衛**：協力プレイ。5ウェーブの敵からサーバーを守る（CPU味方なし）
- **ホット・ポテト**：熱々缶コーヒーを持つと得点、爆発すると減点。タックルで押しつける
- **ストーリーモード**：全4章。会話シーンとボス「エラーコード99」戦。全クリアで限定スキン
- **オンライン対戦**：GAS版のみ。最大7人、足りない分はCPU。WebRTCで直接接続（だめならGAS中継）

## 内容
- マップ17種類（ふつう15＋鬼ごっこ専用2）。氷・ワープ・ボール・掃除ロボ・回るイス・強風・ソースの床など、マップごとに仕掛けがちがう
- マップごとの「外部干渉（人間の手）」イベント：巨大硬貨の落下・台パン・暴風・懐中電灯・吸い込み・照明ショート・冷凍
- アイテム20種類（順位が低いほど強いアイテムが出やすい）
- 試合中のハプニング（停電・地震・大そうじ…）、コンボ、ラストスパート（硬貨1.5倍）
- CPUの強さ4段階、着せかえ（虫7種・色・ぼうし・足あと）、ガチャ、レベル、デイリーミッション

## 操作
- PC: WASD／矢印キーで移動、スペースでタックル、Pで一時停止
- iPad: 画面をドラッグで移動、右下ボタンでタックル

## ファイル
- `index.html` … GitHub Pages 用（three.js を CDN から読み込み）
- `gas/` … Google Apps Script 用
  - `Code.gs`（ページ表示＋オンライン対戦の中継）と `index.html`（GAS上のファイル名は `index`）
- `tools/build_gas.py` … `index.html` から `gas/index.html` を作るスクリプト
  - `python3 tools/build_gas.py node_modules/three/build/three.min.js`（three@0.160.0）

# そらのみなと ～ドット空港経営記～（`sim/`）

小さな島の草原に空港をつくり、世界中（そして宇宙）とつながる「そらのみなと」に育てる空港経営シミュレーション。
3Dの世界を低い解像度で描いてドット絵風にし、人物は2Dのドット絵で表示する「2D×3D」の見た目です（Three.js・HTML 1ファイル）。

## 遊べること
- **建物 約150種類**：滑走路3種・駐機場3種・管制塔・消防署・給油施設・格納庫・貨物ターミナル・ILS・ヘリポート、チェックイン・保安検査・搭乗口・出入国審査、飲食16種・ショップ12種・娯楽、駐車場・空港駅・ホテル・温泉、かざり
- **実在の機材 23種類＋架空2種類**：DHC-6、ATR 42/72、Q400、G650、CRJ900、E175/E190、A220、A320neo、737-800、737 MAX 8、A321neo、767-300ER、A330、787-9/10、A350-900/1000、777-300ER、A380、747-8F ほか（寸法は実機を縮小。メーカー名は「ボーリング」「エアブロー」）
- **飛行機の動き**：横から入って滑走路の延長線にのる進入・5°の降下・フレア・逆噴射での減速・誘導路の走行（小さい機体ほど小回り）・滑走路手前での待機・プッシュバック・離陸・上昇旋回・待機旋回・ゴーアラウンド・後方乱気流の間隔・ボーディングブリッジ・地上車両・衝突防止灯やストロボ
- **航空会社20社（架空）・就航先74都市**：国内線・アジア・長距離・宇宙。路線ごとに機材と便数を選べる。好感度で便数の上限が増える
- **お客さん**：23タイプ（家族は子どもがついて歩く・遅れそうな人は走る・ひとことつぶやく）。入口→チェックイン→保安検査→（出国審査）→お店→搭乗口と1人ずつ歩き、並び、買い物をする。到着した人は手荷物受取所から出口へ。満足度が空港の評価★になる
- **組み合わせ42種**（近くに置くと売上アップ）、**開発41種**、**ランク10段階**、**ストーリー全7章＋エンディング**、**実績62**、図鑑（機材・お客さん・組み合わせ・都市スタンプ）
- 四季・天気（雨・雪・霧・台風）・昼と夜、イベント21種（夏まつりの花火・航空祭・お花見・紅葉・アイドルのライブ…）
- そのほかの挙動：接地のタイヤスモーク、飛行機雲、新路線初便のウォーターサリュート、雪の日の除氷作業、地上スタッフのお見送り、鳥の群れ、風で向きを変える吹き流し、バス停に来るバス、展望デッキで撮影するマニア、夜の誘導灯
- セーブ（自動・3スロット）、引きつぎコード、GAS版はクラウド保存（6文字のコード）

## 操作
- PC：ドラッグで移動、ホイールでズーム、Q/Eで回転、Rで建物を回転、右クリック/Escでキャンセル、スペースで一時停止、1〜3で速さ
- iPad：1本指で移動、2本指でズーム、建物は「タップで場所を決める→もう一度タップで建てる」

## ファイル
- `sim/src/` … ソース（`style.css`・`body.html`・`js/*.js`）
- `sim/index.html` … GitHub Pages 用（three.js を CDN から読み込み）
- `sim/gas/` … Google Apps Script 用：`Code.gs` と `index.html`（GAS上のファイル名は `index`）
- `tools/build_sim.py` … `sim/src` から上の2つを作る
  - `python3 tools/build_sim.py node_modules/three/build/three.min.js`（three@0.160.0）

### GASでの公開手順
1. Apps Script で新しいプロジェクトを作り、`Code.gs` に `sim/gas/Code.gs` の中身を貼る
2. 「ファイル → HTML」で `index` という名前のファイルを作り、`sim/gas/index.html` の中身を貼る
3. 「デプロイ → 新しいデプロイ → ウェブアプリ」（実行するユーザー：自分、アクセス：全員 など）
