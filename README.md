# 自販機の裏の戦い

学校のすみっこで、虫たちが硬貨を奪い合う3D物理アクションゲーム（Three.js・HTML 1ファイル）。

## モード
- **個人戦（陣取り）**：2〜7匹で硬貨を自分の陣地（ふせん）に集める
- **チーム戦（サッカー）**：赤と青に分かれて、相手のゴールに硬貨を入れる
- **鬼ごっこ**：広い専用マップで逃げる・追いかける
- **オンライン対戦**：GAS版のみ。最大7人、足りない分はCPU

## 内容
- マップ13種類（ふつう11＋鬼ごっこ専用2）。氷・ワープ・ボール・掃除ロボ・回るイス・強風など、マップごとに仕掛けがちがう
- アイテム20種類（順位が低いほど強いアイテムが出やすい）
- 試合中のハプニング（停電・地震・大そうじ…）、コンボ、ラストスパート（硬貨1.5倍）
- CPUの強さ4段階、着せかえ（虫7種・色・ぼうし・足あと）、ガチャ、レベル、デイリーミッション

## 操作
- PC: WASD／矢印キーで移動、スペースでタックル、Pで一時停止
- iPad: 画面をドラッグで移動、右下ボタンでタックル

## ファイル
- `index.html` … GitHub Pages 用（three.js を CDN から読み込み）
- `gas/` … Google Apps Script 用
  - `Code.gs`（ページ表示＋オンライン対戦の中継）と `index.html`（GAS上のファイル名は `index`）
- `tools/build_gas.py` … `index.html` から `gas/index.html` を作るスクリプト
  - `python3 tools/build_gas.py node_modules/three/build/three.min.js`（three@0.160.0）
